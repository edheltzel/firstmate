Observational Memory does not search the dark. It keeps a star chart: dated notes stay in the prompt, raw history burns off, and the prefix stays cacheable.

Three orbits

The agent never remembers every word.

Mastra (often heard as Maestra) ships Observational Memory in @mastra/memory 1.1.0. Two background agents watch the thread. The main model sees a stable log, not a retrieved pile.

Outer ring

Recent messages

Exact turns still in play. Grows toward ~30k tokens, then most of it is burned into notes.

Middle ring

Observations

The Observer writes dated, prioritized notes. Those notes stay in context. The raw messages they came from are dropped.

Core

Reflections

At ~40k observation tokens the Reflector rewrites the whole log. Not a third growing layer. A reset that keeps recent detail.

Observe, shrink, repeat

The context window oscillates. It does not sprawl.

0–30kHistory growsObserver buffers in the background every ~6k tokens.
→
30kActivateNotes append. Only ~6k recent history remains.
→
RepeatSlow logEach cycle adds a thin band of observations, not another transcript.
→
40kReflectThe entire observation block is rewritten. Cache misses here, rarely.

Prompt cache is the architecture. New user text appends: full prefix hit. Observation appends notes: partial hit. Reflection rewrites the sky: miss. RAG injects a new constellation every turn, so the prefix never stays still.

Text is the interface

Not a graph. A night log.

Date: 2026-01-15
- ● 12:10 User is building a Next.js app with Supabase auth, due in 1 week (22 Jan)
  - ● 12:10 App uses server components with client-side hydration
  - ● 12:12 User asked about middleware for protected routes
  - ● 12:15 User stated the app name is "Acme Dashboard"

Three dates

  • When the note was written
  • The date mentioned in the content
  • A relative offset (“2 days from today”)

Priority as log level

  • High: keep through reflection
  • Maybe: useful now
  • Info: fine to compress later

Trade

Stay on task, or search a corpus.

Your stack

Recall is a library. OM is a sky chart.

Atlas Recall is a searchable memory store: extract, embed, frecency, skills, dump, doctor. OM is an in-prompt compressor. A scout is scoring the overlap now. Early read: do not replace Recall with OM. Steal the observation log for live session rot; keep Recall for cross-session search.
